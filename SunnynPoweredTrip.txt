## 1. 项目简介 (Introduction)

* **项目名称：** 阳光充足：基于气象与能耗预测物流调度
* **参赛赛道：** 2026 百度地图开发者大赛 —— 智能物流地图应用场景
* **项目立意：** 取名“阳光充足”，寓意通过智能预测让物流运输全程“避开风雨暴雨，迎来平坦通途”。针对物流运输中**突发恶劣天气（暴雨积水）导致履约受阻**以及**新能源/重载货车续航告警与抛锚**的真实痛点，在百度地图现有 TMS+ 与货车导航能力底座上，构建**“预测驱动（Prediction-Driven）”**的智能调度增强引擎[cite: 1, 7]。通过预判沿途气象与地形能耗，实现“动态气象避险”与“精准能量补充（充电/加油）”的自动算路闭环。

---

## 2. 项目目标与核心方向 (Goals & Key Breakthroughs)

项目的核心突破点在于 **“预测（Prediction）”** 以及 **“基于预测的自动化路由二次优化（Prediction-Based Optimization）”**。

### 核心功能三大模块：
1. **沿途气象与路况预测 (Weather & Hazard Prediction)**
   * **气象感知：** 基于路线沿途坐标的逐小时气象预测，评估降水量、风速及能见度。
   * **积水预判：** 结合短时强降雨量预判高风险路面积水区。
2. **气象/地形加权的能耗与补给预测 (Energy & Replenishment Prediction)**
   * **加权衰减模型：** 结合海拔高程变化（上/下坡）以及气象阻力（风阻、暴雨、空调开耗），计算动态百公里能耗。
   * **枯竭点精准预测：** 沿路线分段推算电量/油量，精准定位续航告警坐标点。
   * **补给站匹配：** 以告警点为中心，检索最佳充电桩/加油站，获取位置及联系电话。
3. **基于预测的动态避险与补给重规划 (Prediction-Based Re-Routing)**
   * **避险规避区（avoid_polygons）：** 将预测的强降雨积水高风险区转化为包围盒并避让。
   * **补给途经点（waypoints）：** 将匹配到的补给站作为途经点插入[cite: 3]。
   * **生成最优路径：** 联动百度路线规划 API，一键生成“既避开暴雨积水，又顺路完成补给”的最优履约路线[cite: 3]。

## 3. 现有资源与限制盘点 (Resources & Constraints)

本项目**100% 完全基于百度地图开放平台现有原生 API/SDK 闭环实现**，不依赖非百度的第三方收费数据。

### 3.1 调用的百度地图开放资源
* **百度路线规划 API (Direction API / Truck API)：**
  * 用于基础算路、获取路线 `polyline` 坐标串及里程/时间。
  * 支持传入 `avoid_polygons`（避让区）和 `waypoints`（途经点）进行重规划[cite: 3]。
* **百度天气查询 API (Weather API)：**
  * 基于经纬度查询实时及未来 24 小时逐小时预报（降水量、风力、能见度等）。
* **百度地点检索 API (POI Search API)：**
  * 周边检索模式，用于以预测告警点为中心，检索“充电站”或“加油站”POI，获取名称、地址及 `telephone` 联系方式[cite: 5]。
* **百度地图 JSAPI GL：**
  * WebGL 3D 渲染，用于展示 3D 路线、积水高风险区 Overlay 及环境/能耗剖面图。

### 3.2 技术限制与应对策略 (Constraints & Mitigations)
1. **积水深度限制：** 百度 API 无厘米级实时积水深度接口。
   * *应对：* 采用“降水量预测推算逻辑”（如预报 $>30\text{mm/h}$ 算作高风险积水区），或结合前端用户/司机手动上报的 Overlay 标注。
2. **高程 DEM 限制：** 百度基础 WebAPI 无批量返回高程数值接口。
   * *应对：* 在后端算法中建立简化的地形坡度/区域系数字典，或利用 JSAPI GL 3D 地形展现配合示例高程参数计算。
