# 部署指南

## 一、本地预览（必须用本地服务器）

```powershell
uv run python -m http.server 8080
# 打开 http://localhost:8080/
```

> 直接双击 `index.html` 会因浏览器 CORS 限制读不到 `data/*.json`，页面会提示"数据加载失败"。
> `tools/record_demo.py` 默认从 **8123** 端口取页面，录屏时用 `--bind 127.0.0.1` 起在 8123。

## 二、配置百度地图 AK

1. 到 <https://lbsyun.baidu.com/apiconsole/key> 创建 **浏览器端** AK；
2. 「应用设置」里把 **Referer 白名单**填上：
   - 本地调试：`localhost`、`127.0.0.1`
   - 线上：`kint23.github.io`（或你的域名）
3. 把 AK 填进 `app/config.js` 的 `ak` 字段。

### `ak` 留空也没关系

页面会**自动切到离线示意底图**（自绘的干线 / 雨带 / 高风险积水段 / 补给站，全部数据驱动），
算法、剖面图、对比卡、可解释文本全部照常工作。

这条降级路径是**故意保留**的：它让 Demo 与录屏不依赖网络与配额，永远可复现。
`app/config.js` 里预先填的是**同账号下 ohbj 的浏览器端 AK**（同一域名白名单，本机演示可用）；
**正式提交前建议为本站单独新建一个 AK**，并把域名加进白名单。

> ⚠️ **服务端 AK 与 MCP Token 永远不要写进前端**，也不要提交到仓库（`.gitignore` 已挡住 `app/config.local.js`）。

## 三、部署到 GitHub Pages

纯静态站点，无构建步骤。

```powershell
git add -A
git commit -m "阳光充足：预测驱动的物流避险与补给调度"
git push origin main
```

`.github/workflows/pages.yml` 会在推送到 `main` 时自动：
- 只发布 `index.html` + `app/`（4 个文件）+ `data/`（5 个 json）+ `README.md` + `docs/`；
- 把 `video/正片-*.mp4` 改名成 `video/demo.mp4` 一起发布（README 里引用的就是这个地址）；
- 发布 `banner/*.webp`（README 顶部的可点击动图）；
- 自动启用 Pages（`enablement: true`），无需手动去 Settings 点。

推完等 1–2 分钟，访问 `https://<user>.github.io/SunnynPoweredTrip/`。

## 四、三档备份（本机约定）

沿用 `C:\Users\USER\Music\BACKUP.md` 的三档方案：① 本机 git ② `D:\VSbackup\<name>` ③ GitHub **私有**仓库。

本项目的占位符：

| 占位符 | 值 |
|---|---|
| `$proj` | `C:\Users\USER\Music\SunnynPoweredTrip` |
| `$name` | `backup-dir`（自定，D 盘目录名） |
| `$gh` | `https://github.com/Kint23/SunnynPoweredTrip.git` |

日常：`git push origin main; git push backup main`（一条命令推两档）。

### 两条铁律（ohbj 的血泪教训）

1. **GitHub 仓库必须是 Private**（建仓表单默认是 Public，要手动改）。
   验证可见性用 **匿名 curl 探测**，不要用 `git ls-remote`：
   ```powershell
   curl.exe -sS -o NUL -w "%{http_code}" "https://github.com/Kint23/SunnynPoweredTrip.git/info/refs?service=git-upload-pack"
   # 200 = 公开（危险！）  401/404 = 私有（正确）
   ```
   本机系统级 gitconfig 有 `credential.helper manager`，`git -c credential.helper= ls-remote`
   **禁用不掉**它，私有库也会返回成功 → 曾被误判为"公开"。

2. `BACKUP.md` **绝不可提交**。`C:\Users\USER\Music\BACKUP.md` 含本机用户名、路径与私人邮箱；
   `.gitignore` 已包含 `BACKUP.md`。
   一旦推过，**即使删掉文件 + `git push --force` 重写历史，GitHub 仍会保留被覆盖的旧顶点**
   （可直接用 `api.github.com/repos/<o>/<r>/git/trees/<旧sha>` 取回），要彻底清除只能删库重建。
